# JomJalan Malaysia 🇲🇾

JomJalan Malaysia is an Electron-based desktop travel application developed for the CSC2923 Object Oriented Programming final project.

The application helps users explore popular destinations in Malaysia, check weather information, discover tourist attractions, calculate travel budgets and manage travel plans.

## Features

- Explore 9 popular destinations in Malaysia.
- View destination details and images.
- Check weather information using the Open-Meteo API.
- Get tourist attraction information using the Wikipedia API.
- View travel packages and activities using the JTR Holidays API.
- Receive activity suggestions based on weather conditions and selected destinations.
- Calculate estimated travel budgets.
- Create, view, update and delete travel plans.
- Save travel plans using Local Storage.
- Search and filter travel destinations.

## Technologies Used

- Electron
- JavaScript
- HTML
- CSS
- JSON
- Node.js
- Local Storage

## APIs Used

**Open-Meteo API:** Retrieves current weather information such as temperature, humidity, wind speed and weather conditions.

**Wikipedia API:** Retrieves information about tourist attractions.

**JTR Holidays API:** Retrieves travel packages and activities.

## How to Run the Application

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Install the required dependencies:

   `npm install`

5. Start the Electron application:

   `npm start`
